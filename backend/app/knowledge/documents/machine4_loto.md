# Machine 4 Lockout/Tagout (LOTO) Safety Procedure
DEMO / APPROVED FOR HACKATHON SIMULATION

Machine 4 Lockout/Tagout Isolation Protocol:
1. Notify all nearby operators that Machine 4 is being taken offline.
2. Shut down the machine control interface.
3. Switch off main power breaker PB-4 and attach an approved red safety padlock.
4. Verify zero energy state by attempting a restart at the local control panel before beginning work.

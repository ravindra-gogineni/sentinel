# Machine 4 Approved Tool Specifications
DEMO / APPROVED FOR HACKATHON SIMULATION

Recommended fasteners and tools for Machine 4:
- Motor housing cover bolts: Requires a 14 mm wrench or 14 mm socket driver.
- Mounting bracket screws: Requires a 10 mm hex key or torque driver set to 45 Nm.
- Inspection hatch cover: Requires a standard #2 Phillips screwdriver.
